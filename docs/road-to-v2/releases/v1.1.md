## What shipped

- **Navigation.** Staff sections are Items | Stock | Loans | Self-Service | Activity | Administration (Administration for ADMIN and OWNER only).
- **Avatar menu.** The avatar opens a native popover menu: identity, My account, Public Lending Hub, Sign out. Browsers without the Popover API get a show/hide fallback.
- **Phones (≤ 760 px).** A bottom bar holds Items, Stock, Loans, Self-Service and More. More opens the same menu as a sheet, with Activity and Administration (by role) listed first. Each destination has exactly one place in each layout.
- **Renamed page address.** `/staff/inventory` now permanently redirects (301) to `/staff/items`, keeping its query, so saved links to an item still open it. The API path `/api/staff/inventory` is unchanged.
- **Copy.** Inventory became Items; Stock & Pantry became Stock (Pantry stays a tab); "Inventory settings" became "Stock settings"; the `Inventory` stock area is labelled "General stock"; and Self-Service has one spelling. Stored values are unchanged.
- **Tokens and primitives** in `src/styles.css`: shape and elevation, 44 px and 40 px targets, the bottom-bar size, safe-area insets, documented breakpoints, and 44 px controls on touch screens. Hard-coded radii and durations now use the tokens.
- **Motion.** CSS only, animating transform and opacity: the menu enters and exits, the current-section marker grows in, and the page fades in over 160 ms. All of it is off under `prefers-reduced-motion`.
- **Responsive fixes found in screenshot review.**
  - Below 1100 px the item ID moves under the name.
  - Stock row actions stack on tablets.
  - Activity drops its empty stock column.
  - At 200% text the shell and page actions stay on screen.
  - Focus never lands under either bar (`scroll-padding`).
- **Section code preloading.** Pointing at, touching or tabbing to an in-app link starts loading that page's code.
- **Workflow additions.**
  - `npm run evidence` (`scripts/visual-evidence.mjs`) produces repeatable before/after screenshots and timings.
  - `.github/workflows/ci.yml` runs build, unit, privacy, browser and Worker end-to-end checks.
  - Roadmap decisions: `docs/specs/accepted/road-to-v2/2026-10-02-roadmap-amendments.md`, plus the shared `CLAUDE.md`.

## Known limitations

- **ID sorting on tablets.** Below 1100 px the ID column and its sort header are hidden, as on V1 phones. The ID shows under each name and search finds it.
- **Very large text on very small phones.** At 200% text on a 320 px phone, the bottom-bar labels shorten to "It…", "St…" and so on. Icons and accessible names stay intact.
- **Fallback menu.** In browsers without the Popover API (iOS before 17), the menu opens and closes with its buttons and closes on choice, but not with Escape or an outside tap.
- **End-to-end test order.** Some Worker e2e tests rely on records made by earlier tests, so run the whole suite rather than a `-g` subset. This is proposed for cleanup in `docs/specs/proposed/2026-10-02-road-to-v2-roadmap-amendments.md` (E12).
