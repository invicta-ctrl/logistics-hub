## What changed

### No coloured edge on a rounded box

The 4 px coloured left edge curved into a crescent on rounded boxes. It is removed from:
- `.verdict` in `src/admin.css`, which opens each Administration section: green, amber and red, the green one in Earl's screenshot;
- `.banner--ok` and `.banner--warn`;
- `.kit-part` in `src/kits.css`;
- the chosen search result, `.palette__option[aria-selected]` in `src/search-palette.css`.

Tone stays with each box's icon or badge. Amber and red boxes keep a tinted fill and a 1 px tinted border; a red verdict gains the tint an amber one already had. The chosen search result keeps its tinted fill, with a 1 px ring.

Straight stripes on square rows (open row, overdue loan) stay, because they have no radius.

### Speed

**What was measured.** All figures are from 2026-11-04, scripts kept in the writer's scratch.

Live site, read-only, from the office network (Cloudflare edge `SJC`), median of 6:

| Request | Median |
|---|---|
| Static file | 254 ms |
| API with no query | 254 ms |
| 1 D1 query (catalog 304) | 397 ms |
| 3 D1 queries (catalog 200) | 717 ms |

Each D1 call costs about 150 ms from there.

Local Worker (`Server-Timing`):
- every staff page asks for three answers: the session, the attention summary and its own data;
- each answer makes 2–5 D1 calls, the session check first.

Browser at a 4× CPU slowdown:
- **Administration, idle:** 151 style recalculations in 2 s from two endless animations, the rail glint and the breathing live dot.
- **Scrolling:** the live Self-Service list scrolled smoothly once loaded (1 janky frame of 63). A Chrome trace of the staff Items list showed about 1.4 s of painting for 12 wheel steps. Most of the remaining "scroll cost" in the first probe was the test tool itself.

**The changes:**
1. `wrangler.jsonc`: `"placement": { "mode": "smart" }`. The Worker runs beside D1, so its calls are nearly free and the visitor pays one long hop.
   - With `run_worker_first`, file requests also pass through the placed Worker. A first visit's files can take one hop longer. Hashed files are cached for a year, and the service worker keeps them.
2. `src/worker.ts`: the public catalog reads the catalog and the Self-Service setting together.
3. `src/self-service.ts`: `selfServiceCatalog()` reads its items and shared places together.
4. `src/styles.css` and `src/admin.css`: the rail glint (`rail-glint`) and the breathing dot (`dot-breathe`) are removed. The lit plate and the dot stay, still.
   - The browser test that pinned them now asserts that an idle staff page runs no endless animation.

**Not changed:** API answers, permissions, data, CSP, caching headers.

**Not done:**
- D1 read replication: a production database setting, which needs its own owner authority and Cloud Operations.
- Table layout of the Items list: a first-draw hitch, about 0.1 s at normal speed.
