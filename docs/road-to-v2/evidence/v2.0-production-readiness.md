## Open items for Earl (not changed here)

Both were done by Earl on 2026-10-08. Item 1 was checked afterwards: the beacon is gone from `/`, `/lending` and `/staff` (0 of 3
pages). Item 2 is Earl's report of the iPhone check.

1. **Cloudflare Web Analytics is injecting its beacon** into every HTML page, and the app's CSP (`script-src 'self'`) blocks it: a
   console error on every load, and no analytics collected. This is a Cloudflare setting, so it was not changed. Either turn off Web
   Analytics' automatic setup for `logistics.hausc.org` (dashboard > Web Analytics, or the zone's Speed/Observability setting), which
   matches the app's no-third-party-scripts posture; or decide to keep analytics and allow its two origins in the CSP.
   Rollback: switch it back on.
2. **Real iPhone check before reopening Self-Service.** In Playwright's WebKit on Windows the tab crashes when an item is opened from
   the Self-Service home with the picture morph. Apple's Safari was not available to confirm or rule it out. Self-Service is closed
   on production, so no student meets it today. Before reopening: on an iPhone, open Self-Service, tap an item on the home screen, and
   confirm the item page opens. If it crashes, the fix is to skip the morph on WebKit.
