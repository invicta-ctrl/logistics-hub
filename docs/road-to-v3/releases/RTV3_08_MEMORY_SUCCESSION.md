# V2.8 (RTV3-08) — Operational Memory & Succession

**Release identity:** planned product **V2.8**; stable internal milestone **RTV3-08**. Historical V3.x roadmap names are retired. Verify deployment identity before announcing the release; ship required architecture, modularization, and security improvements within this same release (Engineering Constitution §2A).

## Outcome
Preserve institutional continuity across semester/year turnover without making generated memory authoritative truth.

## Capabilities
- State of Logistics;
- turnover pack;
- known operational risks;
- current responsibilities;
- unresolved commitments;
- key resource/process knowledge;
- succession/handover summaries;
- durable links to authoritative records.

## AI
May assist synthesis from permitted structured data.
Must not expose prohibited identity/private evidence.
Generated summaries always link back to authoritative sources.

## Human Operations
Expose single-person dependency and handover needs without scoring staff performance.

## Independence
Operations do not depend on generated memory artifacts.
