## Contracts and security
Validate external input at server boundary; typed API contracts and stable IDs. Enforce tenant/role authorization on every sensitive action; test denial. Secure sessions and least privilege; no secrets in browser, source, logs or public artifacts. Apply relevant HTTPS, contextual encoding/sanitization, CSRF, CSP/security headers, OAuth PKCE/token validation and precise CORS (not authorization); review third-party scripts and applicable isolation/integrity controls. Idempotency for retries and mutation effects; transactional integrity, unique constraints, timeouts and bounded retries. No client-only payment/authorization claims. Structured redacted logs, request correlation, explicit error responses.
