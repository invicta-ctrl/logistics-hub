## Preferred stack
TypeScript; React; React Router with SSR when appropriate; Vite and Cloudflare Vite plugin; Tailwind CSS; shadcn/ui with one appropriate primitive family (Base UI or Radix; preserve existing choices); ShadcnStore and ReUI as reference; TanStack Table; React Hook Form and typed schema validation (e.g. Zod when justified); Lucide; Figma (mandatory for new material interfaces and shared design changes); Storybook (mandatory shared component catalog). Cloudflare Workers + Static Assets; existing Wrangler configuration for current apps, current Cloudflare CLI for new apps only after verifying supported framework; D1 and Drizzle when relational persistence is needed; R2 when objects are needed; OpenAPI/typed schemas for cross-product contracts; Playwright; axe-core; GitHub Actions and Workers Builds (one release trigger); Claude Code Desktop and Astral Suite; ChatGPT for management/audit; Codex only by explicit task-specific owner authorization. Node LTS and package manager version pinned per repo; lockfiles mandatory. No unnecessary dependency or migration. Optional services (Durable Objects, Queues, KV, AI) only for an accepted concrete requirement.
